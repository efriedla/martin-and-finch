# Martin & Finch

The landing page for Martin & Finch, a back-office studio: clear systems that keep small businesses running (bills, invoices, stock, shipping, customer updates).

- One static page: `index.html`, with no build step and no framework.
- Fonts: Work Sans (headings, labels, buttons) and Alegreya Sans (text), from Google Fonts.
- Contact form: posts to [FormSubmit](https://formsubmit.co) and is delivered to the studio inbox. The first message after deploying sends an activation email that must be confirmed once.
- Hosting: GitHub Pages from `main`, root folder.

Plan and decisions live in the ClumpAndPlay repo: `STUDIO_PLAN.md`.
